# Preguntas Frecuentes (FAQ) - UniRoute

## 1. ¿Qué es UniRoute?

UniRoute es un proyecto orientado a facilitar la consulta de información relacionada con rutas y ubicaciones de interés para sus usuarios.

## 2. ¿Cuál es el objetivo de UniRoute?

Su objetivo es ofrecer una interfaz organizada que facilite la navegación y la consulta de la información disponible en la aplicación.

## 3. ¿Cómo puedo navegar por la aplicación?

Puedes utilizar las opciones y secciones disponibles en la interfaz para acceder a las funciones que ofrece UniRoute.

## 4. ¿Qué puedo hacer si una sección no funciona correctamente?

Verifica que la aplicación esté cargada correctamente. Si el problema continúa, informa al equipo de desarrollo para que pueda revisarlo.

## 5. ¿Cómo puedo consultar la documentación de UniRoute?

Puedes consultar el manual de usuario y las guías disponibles en el portal de documentación del proyecto.
