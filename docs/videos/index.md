# Guía Visual de Navegación y Uso de la Aplicación UniRoute

## Introducción

Bienvenido a la guía visual de UniRoute, una aplicación diseñada para facilitar la navegación y ayudar a los usuarios a comprender el funcionamiento de sus principales pantallas.

Esta guía presenta el videotutorial del proyecto y permite conocer visualmente cómo utilizar la aplicación.

## Objetivo del videotutorial

Mostrar el funcionamiento de UniRoute y orientar al usuario durante la navegación por la aplicación.

## Elementos de la guía visual

- **Burbujas numeradas:** identifican elementos importantes de la pantalla.
- **Recuadros de color:** resaltan botones, secciones o funciones relevantes.
- **Flechas indicativas:** señalan dónde debe dirigir su atención el usuario.

Estos elementos facilitan la comprensión de la interfaz y ayudan al usuario a seguir las indicaciones.

## Importancia de la guía

La guía visual permite comprender mejor la interfaz de UniRoute, reconocer sus elementos principales y seguir las indicaciones de navegación de manera sencilla.
