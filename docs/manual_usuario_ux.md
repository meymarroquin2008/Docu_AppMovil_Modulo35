
# Guía Visual de Navegación y Uso de la Aplicación UniRoute

Bienvenido a la guía de uso de UniRoute. Este manual te explicará paso a paso cómo utilizar las funciones principales de forma rápida y sencilla para explorar carreras profesionales y conocer las universidades donde puedes continuar tus estudios.

## 2. Paso a Paso: Cómo Iniciar Sesión

Para acceder a tu cuenta en UniRoute, realiza las siguientes acciones:

![Pantalla de Inicio de Sesión](assets/login_anotado.png)

1. **Correo Electrónico (1):** Ingresa la dirección de correo con la que creaste tu cuenta.
2. **Contraseña (2):** Escribe tu clave de acceso personal.
3. **Botón "Ingresar" (3):** Presiona el botón para entrar a tu pantalla principal.

---

## 3. Paso a Paso: Cómo Crear una Cuenta

Para crear una cuenta nueva en UniRoute, realiza las siguientes acciones:

![Pantalla de Registro](assets/registro_anotado.png)

1. **Nombre Completo (1):** Agrega el nombre completo del usuario.
2. **Correo Electrónico (2):** Escribe el correo electrónico que utilizarás para la cuenta.
3. **Registrarse (3):** Presiona este botón para crear la cuenta.

---

## 4. Exploración de Carreras Profesionales

UniRoute permite a los estudiantes explorar diferentes áreas profesionales para conocer las carreras disponibles según sus intereses.

1. **Selección de Área:** Explora las áreas profesionales disponibles en la aplicación.
2. **Consulta de Carreras:** Selecciona el área que te interesa.
3. **Información de la Carrera:** Consulta los detalles disponibles sobre la carrera seleccionada.

---

## 5. Consulta de Universidades

Para conocer las universidades relacionadas con una carrera, realiza las siguientes acciones:

1. **Seleccionar Carrera:** Elige la carrera profesional que deseas consultar.
2. **Universidades Disponibles:** Revisa las universidades que ofrecen esa carrera.
3. **Información de la Universidad:** Consulta los datos disponibles sobre la institución seleccionada.
