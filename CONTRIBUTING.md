
# Guía de Contribución

Gracias por colaborar con nuestro proyecto de documentación.

## 1. Reporte de errores

Si encuentras un error, repórtalo en la sección Issues de GitHub. Describe el problema, los pasos para reproducirlo y el resultado esperado.

## 2. Ramas de trabajo

Utiliza los siguientes prefijos para organizar los cambios:

- `feature/`: para agregar nuevas funcionalidades.
- `fix/`: para corregir errores.
- `docs/`: para realizar cambios en la documentación.

## 3. Normas de código y documentación

- Escribe código claro y organizado.
- Utiliza nombres descriptivos para archivos y variables.
- Mantén la documentación actualizada.
- Verifica que los enlaces funcionen correctamente.
- Respeta la estructura existente del proyecto.

## 4. Proceso de contribución

1. Revisa los Issues existentes antes de comenzar.
2. Crea una rama para tu modificación.
3. Realiza los cambios necesarios.
4. Comprueba que todo funcione correctamente.
5. Envía los cambios para su revisión.

## 5. Comunicación

Describe cada cambio de manera clara y respetuosa para facilitar el trabajo en equipo.
